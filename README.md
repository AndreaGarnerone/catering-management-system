# Catering Management System

This repository contains a **Software Application Development project** focused on the design and partial implementation of an application for managing a catering company.

The project was developed following the **Unified Process (UP)** methodology and makes extensive use of **UML modeling** to describe requirements, system behavior, and architecture.

---

## Project Goals

The objective of the project is to design a system that supports the management of a catering company, with particular attention to:

- Kitchen task planning
- Staff shift scheduling
- Assignment and coordination of culinary activities
- Operational workflows in food preparation

The emphasis is placed on **analysis and design**, rather than on full implementation.

---

## Development Methodology

The project follows the **Unified Process (UP)**, including:

- Requirements analysis
- Scenario definition
- Incremental and iterative design
- Separation between analysis models and implementation

UML diagrams are used consistently to document each phase.

---

## UML Artifacts

The repository includes the following UML models:

- **Use Case diagrams** and detailed scenarios
- **Domain Model** (conceptual classes and relationships)
- **Sequence Diagrams** describing system interactions
- **Design Class Diagrams (DCD)**
- Supporting documentation for design decisions

These artifacts describe the core logic of shift management and kitchen task coordination.

---

## Application Design Focus

The central design challenge addressed in the project is the **management of kitchen operations**, including:

- Staff roles and responsibilities
- Assignment of cooking tasks
- Scheduling of work shifts
- Coordination between kitchen staff and management

The models aim to reflect realistic workflows found in catering businesses.

---

## Implementation

Based on the UML design, part of the application was implemented in **Java**, following object-oriented principles and maintaining consistency with the design models.

The implementation is not intended to be complete, but rather to demonstrate the transition from UML design to code.
